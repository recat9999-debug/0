# ドラッグでリアクション

`index.html` をブラウザで開くだけで動きます。キャラの頭・手・おなかをドラッグして離すと、パーツごとに設定したコマ送りアニメが再生されます。

## 画像の差し替え
- **画面から**: 右パネルの各枠に画像をドラッグ＆ドロップ（複数枚はファイル名順にコマになります）。「保存」でブラウザに保存、「JSON書き出し」でファイルに保存できます。
- **ファイルで**: `images/` に画像を置き、`index.html` の `DEFAULT_CONFIG` の `frames` を `"images/head_01.png"` のようなパスに書き換えます。

## パーツの位置
「編集モード」で四角をドラッグして移動、右下の丸で大きさを変更。「＋ パーツを追加」で掴める部分を増やせます。
